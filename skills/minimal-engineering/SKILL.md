# Minimal engineering

**Purpose:** Reuse first. Make the smallest change that solves the problem.

## Rules
1. Inspect what already exists before building anything.
2. Prefer an existing tool or function over a new one.
3. No speculative abstractions, no dependency without a stated reason.
4. Leave the code simpler than you found it.

## Done when
The change meets the acceptance criterion and removes at least as much complexity as it adds.
